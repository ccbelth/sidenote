# SideNote 侧边备忘

贴在屏幕右边缘的备忘录。鼠标移到最右侧就滑出来，不切应用也能记一笔。单文件前端，无框架、无依赖、无后端。

## 功能

- 左侧彩条是分类，可拖动排序，右键换色
- 每条笔记用几何图形加颜色区分：圆、方、三角、菱形、五边形、六边形、星、环。图形轨道同样可拖动排序
- 富文本：加粗、倾斜、划去、下划线、高光
- 录音与语音转写，识别语种跟随翻译源语言切换
- 插图、拖拽图片、手绘简图，画板有画笔、直线、矩形、圆、三角、橡皮
- 划词翻译，语言池可勾选启用三十门语言，接口走 MyMemory 公开服务
- 追踪：给一个习惯设间隔天数，画一条时间轴，到期脉冲提示，打卡留痕
- 两种形态：348×480 的侧卡，和贴边全高的长条。可固定成不自动收起

## 运行

浏览器：双击 index.html 即可。数据存在 localStorage，键名 sidenote.v3。

桌面版：先跑 makeicon.js 生成图标，再执行 build.sh，或者用 build_app.sh 直接塞进现成的 Electron 框架。两者都需要本机有 Node。

## 快捷键

Command + E 显示或隐藏，Command + N 新建一条，Esc 收起。

## 技术

原生 HTML、CSS、JS，没有构建步骤。图形用 SVG 现算，拖拽排序基于 pointer 事件，动画交给 CSS transition。桌面版只有一个 main.js 托盘与窗口逻辑。

## 说明

仓库不含任何个人笔记。首次打开会写入一组演示数据，定义在 seed() 里，之后只存在本机 localStorage。图标与打包产物没有放进仓库。
